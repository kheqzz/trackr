# Trackr

A simple Flutter application for tracking and managing activities.

> **Status:** Initial Version

---

## English

### About

Trackr is a Flutter project currently in its initial development stage.

The application is kept simple for now, with a basic structure and interface.

### Current State

- Light Mode only
- English language only
- Basic Flutter application structure
- Home page as the main screen
- Material 3 theme with a purple color scheme

### Theme

The application currently uses Light Mode only.

Although a dark theme is already defined in the code, it is not enabled yet. The application is currently configured with:

```dart
themeMode: ThemeMode.light,
```

### Language

The application currently uses English only.

Indonesian localization has not been implemented.

### Getting Started

Make sure Flutter is installed on your machine.

Install the dependencies:

```bash
flutter pub get
```

Run the application:

```bash
flutter run
```

### Project Structure

```text
trackr/

│   ├── main.dart
│   └── page/
│       └── home_page.dart
├── test/
├── pubspec.yaml
└── README.md
```
